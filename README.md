<summary><strong>📦 安装与首次使用</strong></summary>

### 安装

1. 正常退出游戏。
2. 确认游戏已具备与当前客户端兼容的 BepInEx 环境。本包提供 HelperVIP 插件、观察器与执行器，不包含完整 BepInEx 安装环境。
3. 将发布包内的 `BepInEx` 文件夹合并到 **`BrownDust II.exe` 所在目录**，保留完整目录结构，不要只复制一个 DLL。
4. 本包的执行器依赖 **.NET 8 运行环境**；安装与客户端架构匹配的版本。
5. 正常启动游戏，按 `F10` 打开功能中心。

安装后的关键文件：

```text
游戏目录/
├─ BrownDust II.exe
└─ BepInEx/
   ├─ plugins/
   │  ├─ HelperVIP/HelperVIP.dll
   │  └─ BrownDustRhythmProbe/BrownDustRhythmObserver.dll
   └─ HelperVIP/
      └─ Worker/                  ← 保留完整执行器目录
```


### 更新

先正常退出游戏，再备份并替换本包对应的插件、观察器和完整 `Worker` 目录。不要混用不同版本文件，也不要覆盖其他插件。

游戏客户端更新后，需要重新确认兼容性。出现版本不匹配时先停止使用，等待适配。

### 通用操作

| 操作 | 作用 |
| --- | --- |
| `F10` | 打开功能面板；运行中打开面板会安全停止当前任务 |
| `F12` | 停止当前任务并释放持有的输入 |
| 面板中的“隐藏” | 收起面板 |
| 当前状态栏 | 查看执行进度、完成数量或停止原因 |

同一时间运行一个任务。开始前关闭聊天输入和无关弹窗；不要在自动运行时同时手动操作相同的小游戏。

<summary><strong>🎨 资源导出｜当前页面素材与 ModStudio 配合使用</strong></summary>

### 导出步骤

1. 在游戏中打开需要导出的**角色皮肤展示页**，等待立绘加载完成。
2. 按 `F10` 打开功能中心，进入 **素材导出**。
3. 点击 **导出 Spine 素材**，查看面板中的导出数量、保存路径或失败提示。
4. 点击 **打开 VIP 导出目录**，找到本次导出的批次文件夹，再进入对应资源 ID 的文件夹。
5. 如需继续预览、编辑贴图或制作 MOD，打开 [ModStudio](https://github.com/gamechao/ModStudio)，选择 **导入游戏导出**，导入其中一个资源文件夹。

### 文件保存在哪里？

VIP 面板导出的素材保存在游戏目录下：

```text
BepInEx/HelperVIP/exports/<批次>/<资源ID>/
```

每份完整素材包含 `skin.atlas`、`skin.skel` 或 `skin.json`、对应的 PNG 贴图、`.modfile` 和 `导出来源.txt`。导入 ModStudio 时选择这一层资源文件夹，并保留完整文件。

### 使用说明

- 导出的是**当前页面已加载、处于激活状态的 Spine UI 素材**，并非一次导出全部游戏资源。
- 如果提示没有可导出的立绘，返回角色皮肤展示页，等待加载完成后再试。
- 如果其他插件替换了立绘，导出内容可能包含替换后的素材。
- 以 `.partial` 结尾的是未完成目录，请查看失败提示，不要作为完整素材导入。
- 原独立版 BrownDustHelper 的 `F9`、配置和导出目录保持不变；本节介绍的是 VIP 面板内的导出入口。
- 本功能负责导出素材；MOD 的编辑、导出与游戏内加载需使用对应工具。

<summary><strong>🎵 节奏自动演奏｜选曲、难度与连续演奏</strong></summary>

### 开始演奏

1. 在游戏中进入音游入口或选曲页面。
2. 按 `F10` → **节奏自动演奏**。
3. 选择歌曲与难度。
4. 按需开启 **正式结算后自动重开**，填写总局数。
5. 点击 **开始演奏**，保持游戏在前台，等待正式结算。

### 支持的选择

| 歌曲 | 难度 |
| --- | --- |
| Seaside Memories | Normal / Hard / Challenge |
| Sunshine | Normal / Hard / Challenge |
| Splash Queen | Normal / Hard / Challenge |
| Beachside Angels | Normal / Hard / Challenge |
| Summer Knight | Normal / Hard / Challenge |

### 总局数怎么填？

- **1**：完成一局后结束。
- **大于 1**：开启自动重开后，完成指定总局数后结束。
- **0**：开启自动重开后持续演奏，直到手动停止或保护停止。
- **关闭自动重开**：只执行当前一局，局数设置不会单独触发重开。

自动重开只在读取到对应歌曲、难度的正式结算后执行。状态栏会显示已完成局数、分数和 Miss 数。

### 使用时注意

- 音游使用系统键鼠输入，**需要保持游戏前台**，不支持像钓鱼一样切到其他窗口继续演奏。
- 自动处理已适配的音符与 Fever 阶段，不承诺每局满分或零 Miss。
- 切走窗口、观察数据异常或出现未知界面时可能保护停止。处理原因后重新开始。
- 随时按 `F12` 停止；打开 `F10` 面板也会停止演奏和后续自动重开。

<summary><strong>🎣 自动钓鱼｜单次、连续与后台运行</strong></summary>

### 开始钓鱼

1. 手动进入钓鱼场景，准备鱼饵、装备和钓点，回到可抛竿状态。
2. 按 `F10` → **自动钓鱼**。
3. 选择 **前台操作** 或 **后台操作**。
4. 填写抛竿次数，按需设置自动恢复。
5. 点击 **开始自动钓鱼**。

任务会依次完成：**抛竿 → 等待咬钩 → 提竿 → 搏鱼 → 收鱼 → 关闭结果页 → 下一竿**。满包时按下方保留规则整理，核验售后库存后关包续钓。

### 抛竿次数怎么填？

| 设置 | 行为 |
| --- | --- |
| 1 | 抛竿一次，完成本轮流程后结束 |
| 大于 1 | 达到指定抛竿次数后结束 |
| 0 | 持续运行，直到手动停止或保护停止 |

**次数按抛竿计算，收鱼数量另行统计**，两者可能不同。

### 前台与后台有什么区别？

| 模式 | 切到其他窗口后 | 适合场景 |
| --- | --- | --- |
| 前台操作 | 失焦暂停，回到游戏后条件满足再继续 | 模拟系统输入，优先稳定性与安全性 |
| 后台操作 | 可继续提竿、搏鱼、收鱼及联动整理 | 同时操作其他窗口 |

后台模式无需占用桌面鼠标或切回游戏窗口。请保持游戏运行；**切到其他窗口已实测，最小化、锁屏和系统睡眠不在已验证范围内**。

模式和恢复开关在开始时确定；修改设置请先停止，再启动新任务。

### 不想等满包？

使用 **立即整理并继续钓鱼**：按当前库存执行整理，完成后继续所设次数的钓鱼。可用于提前腾出空间或检查整理流程，不必等背包满400格。

工具不会自动购买鱼饵、换装备或切换钓点。遇到未知弹窗、无法核对的状态或没有可安全出售的鱼时，会保护停止。

<summary><strong>🐟 背包整理｜传说、锁定与 MAX / MIN 保留规则</strong></summary>

### 哪些鱼会保留？

| 鱼的情况 | 整理规则 |
| --- | --- |
| 传说鱼 | 全部保留 |
| 已锁定的鱼 | 全部保留，包括重复鱼，不解锁 |
| 普通、稀有鱼带 MAX 标记 | 每个鱼种保留一只 |
| 普通、稀有鱼带 MIN 标记 | 每个鱼种保留一只 |
| 普通、稀有鱼没有 MAX / MIN 标记 | 未锁定且无其他保护时，可以出售 |
| 未知品质、数据不完整或其他保护状态 | 保留 |

**MAX / MIN 指游戏实际显示的标记，不是当前背包里相对最大或最小的尺寸。** 某个鱼种没有标记鱼时，不会为了凑一对而保留普通尺寸。

同鱼种、同标记重复时，优先复用已锁定的鱼作为保留名额；没有已锁定的候选时，保留唯一背包 ID 较小的一只。所有已锁定的重复鱼仍然全部保留。

例如：某鱼种有两只未锁定 MAX、一只未锁定 MIN、三只普通尺寸，整理后保留一只 MAX 和一只 MIN。若其中一只普通尺寸已锁定，它也会保留。

### 先看预览，再独立出售

1. `F10` → **鱼类背包** → **读取出售预览**。
2. 查看保留与待售清单。**预览不会出售，也不要求先打开游戏鱼包。**
3. 若要独立出售，先打开游戏鱼类背包、筛选全部鱼类，退出锁定模式并清空原有勾选。
4. 回到面板重新读取预览，点击 **按预览整理出售**，保持游戏前台。

需要后台整理并续钓时，请使用自动钓鱼页面的 **后台操作 → 立即整理并继续钓鱼**。

### 自动整理怎样保护库存？

- 根据待售数量选择逐项勾选，或全选后反选保留鱼，并自动翻页检查。
- 最终勾选名单必须与计划完全一致，才会进入出售确认。
- 每轮出售确认只提交一次；提交后等待库存回执，不反复点击确认。
- 售后逐只核对剩余鱼的 ID 与属性，确认保护鱼完整后才关包续钓。
- 库存、锁定状态、筛选或勾选异常时停止，不强行出售。若已提交出售，停止操作不会撤销已完成的交易。

<summary><strong>🔄 钓鱼自动恢复｜开启方式与安全边界</strong></summary>

在自动钓鱼页点击开关，确认显示 **自动恢复：开启**，再启动任务。默认关闭，可按需要选择。

### 开启后会怎样？

执行器意外退出或遇到可恢复中断后，插件会等待安全状态，尝试从原任务检查点接续；计数、选鱼和出售进度随任务保存。

- 恢复等待依次为约 **3 / 10 / 30 秒**。
- 最多连续恢复 **3 次**，另有10分钟内最多5次的频率保护；达到限制后停止。
- **手动按 F12、点击停止或打开 F10 面板，不会触发自动重启。**
- 正常达到设置次数后，也不会自动重启。
- 出售是否提交不明确时，采取保护停止，不通过重复确认来尝试恢复。
- 自动恢复要求游戏仍在运行，不负责重启游戏、登录或处理未知网络弹窗。

<summary><strong>❓ 常见问题与反馈</strong></summary>

### 按 F10 没有面板

检查插件、观察器和完整 Worker 目录是否安装到正确位置；查看 `BepInEx/LogOutput.log` 是否出现 HelperVIP 加载记录。修改或更新插件后需重新启动游戏。

### 音游切走就停止，钓鱼却可以后台？

两者输入方式不同。音游需保持前台；钓鱼只有在启动前选中“后台操作”才会后台运行。

### 次数设为0仍然停止

0表示不设次数上限，仍会保留版本、未知弹窗、库存和恢复次数等保护。按 F10 查看停止原因；打开面板本身也会停止任务。

### 整理停在选鱼或确认界面

先按 F12 停止，保留日志，不要反复手动确认。确认尚未出售时可取消选择、关闭背包；排除原因后重新读取预览或重新启动整理。若出售已经提交，先核对库存，避免重复操作。

### 可以一直挂机吗？

支持次数0连续运行，但不承诺无限时稳定。客户端更新、网络状态、未知鱼类技能或界面变化都可能需要人工处理。首次连续运行建议先观察几个完整循环。

### 反馈问题时提供什么？

- 插件版本、前台/后台模式、次数、自动恢复是否开启。
- 停在哪个阶段，以及面板状态栏文字或截图。
- 问题发生的大致时间。
- `BepInEx/LogOutput.log` 和对应任务目录 `BepInEx/HelperVIP/sessions/` 的相关记录。

音游报告另见 `BepInEx/HelperVIP/Worker/reports/`。整理记录包含计划、操作、售后核验和完成结果；分享前请检查日志中是否带有需要隐藏的本机路径等信息。
